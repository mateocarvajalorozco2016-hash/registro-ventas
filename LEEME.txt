COMO OBTENER EL EXE SIN INSTALAR PYTHON

Esta versión usa GitHub Actions para compilar el programa en un computador Windows de GitHub.
Tú NO necesitas instalar Python, Apache ni XAMPP en tu computador.

Pasos:
1. Crea una cuenta gratuita en GitHub.
2. Crea un repositorio nuevo.
3. Sube app.py y la carpeta .github/workflows con el archivo crear-exe.yml.
4. En GitHub entra a Actions.
5. Selecciona "Crear EXE de Windows".
6. Pulsa "Run workflow".
7. Cuando termine, descarga el artefacto "RegistroVentas-Windows".
8. Dentro estará RegistroVentas.exe.

Nota:
Esta es una prueba técnica del método de compilación en la nube. La interfaz y funciones se seguirán mejorando antes de usarla como programa definitivo.
